# 🛍 Card Slim (Учебный интернет-магазин)

Простой интернет-магазин (pet-проект), созданный для изучения работы с маршрутизацией, базой данных и сессиями на микрофреймворке **Slim**. Проект имитирует ключевые процессы оформления заказа.

## 🚀 Основной функционал

*   **Каталог товаров:**
    *   Отображение списка категорий товаров.
    *   Фильтрация и корректный редирект для отображения товаров конкретной категории.
*   **Карточка товара:**
    *   Подробная страница о товаре с возможностью добавить его в корзину.
*   **Корзина и заказы:**
    *   Симуляция добавления товаров в заказ.
    *   Все созданные заказы сохраняются в базе данных.
    *   Простая «админка» для просмотра, изменения статуса заказа или его удаления.

## 🛠 Технологии

*   **Backend:** PHP 8+, Slim Framework 4
*   **Шаблонизация:** Twig
*   **База данных:** MySQL
*   **Окружение:** Docker / Docker Compose
