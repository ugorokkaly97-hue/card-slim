Реализовано:
1. Отображение категорий товаров, корректный редирект на нужную категорию и соответствующие товары.
2. Отобраение товаров и корректный редирект на подробности о товаре. Кнопка с возможностью добавления товара в корзину.
3. При заказе товара заказ корректно отображается в базе и их можно будет посмотреть в корзине(подобие админки)
4. В "админке" можно изменить статус заказа или удалить его.
